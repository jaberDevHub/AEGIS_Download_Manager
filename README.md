# Aegis Download Manager

A modern, high-speed, zero-license desktop download manager built with Python and PyQt6. Features multi-connection acceleration, integrated video/stream extraction (YouTube, HLS, DASH), FFmpeg post-processing, clipboard sniffing, and a zero-setup browser extension.

Website: [Aegis Download Manager](https://aegis-download-manager.vercel.app/)

---

## ⚡ Quick Start

### 1. Download & Run
1. Go to [Aegis Download Manager](https://aegis-download-manager.vercel.app/) and download the app.
2. Extract the ZIP file.
3. Open `Aegis Download Manager.exe` to run.

---

### 2. Browser Extension Setup
1. Open your browser extensions page (`chrome://extensions`, `edge://extensions`, or `brave://extensions`).
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select the `browser_extension` folder.

Done!
